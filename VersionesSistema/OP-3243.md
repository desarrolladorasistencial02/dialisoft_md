**Comentario 47734 · 2026-10-06T08:53:28.347-0500 · Carlos Santiago Gonzalez Cuellar**

```
Novedades y Modificaciones
Se declaran explícitamente las propiedades utilizadas por la clase versiones_sistema_model, evitando la creación de propiedades dinámicas durante la ejecución del crontab sincronizar_commits_produccion.php y corrigiendo los mensajes PHP Deprecated generados por PHP 8.4.
Archivo: system_modules/VersionesSistema/model/versiones_sistema_model.class.php
Clase: versiones_sistema_model
Antes:
Las propiedades $app, $limit_pagination y $ultima_version eran utilizadas en la clase sin encontrarse declaradas previamente.
PHP 8.4 generaba mensajes PHP Deprecated al crear dinámicamente estas propiedades durante la ejecución del crontab.
La situación se presentaba al ejecutar sincronizar_commits_produccion.php.
OP-3243_1.pngDespués:
Se declaran previamente las propiedades $app, $limit_pagination y $ultima_version dentro de la clase versiones_sistema_model.
Las propiedades quedan definidas como privadas mediante:
private $app;
private $limit_pagination;
private $ultima_version;
Se evita la creación dinámica de propiedades durante la ejecución de la clase.
Se eliminan los mensajes PHP Deprecated asociados a estas propiedades al ejecutar el crontab con PHP 8.4.
OP-3243_2.png
```
