**Comentario 46113 · 2026-04-30T15:27:27.589-0500 · Oscar Fabian Castañeda**

```
Novedades y Modificaciones
Se ajusta la cantidad de caracteres del campo DESCRIPCIÓN al momento de crear o modificar un cargo en el tarifario. Esta actualización solo aplica para República Dominicana. 
OP-2964_1.pngAntes:
El campo DESCRIPCIÓN permite ingresar un máximo de 600 caracteres. 
OP-2964_1.pngDespués:
El campo DESCRIPCIÓN solo permite ingresar un máximo de 80 caracteres.
OP-2964_2.png
```
