```
Novedades y Modificaciones
Se reemplazó el uso de sizeof() por la validación !empty(), con el fin de evitar errores al procesar valores que puedan llegar vacíos o que no correspondan a una estructura contable. Adicionalmente, se inicializó la variable $datos como un arreglo vacío dentro de la consulta de pacientes, garantizando que siempre cuente con un valor válido antes de ser utilizada.
Con estos ajustes se corrige la incompatibilidad presentada en PHP 8.4, se evita que el flujo de ejecución se detenga cuando la consulta no retorna información y se garantiza el correcto ingreso al sistema con el usuario creado y asociado al paciente.
```
