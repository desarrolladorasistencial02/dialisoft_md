```
Novedades y Modificaciones
Menú principal
Se incorporó un menú principal con tres tarjetas independientes que permiten acceder a Gestión Crontabs, Gestión Correos y Gestión Condiciones.
OP_3009_1.pngGestión Crontabs
Antes
Antes el submódulo Crontabs tenía una navegación básica y un formulario superior con los botones Guardar, Cancelar y Refrescar.
OP_3009_2.pngAnteriormente todos los crontabs se visualizaban en una tabla que incluía su información y las opciones para editar o eliminar cada registro.
OP-3009_3.pngDespués de registrar un crontab, el sistema mostraba una alerta breve con el texto Guardado.
OP_3009_4.pngAl hacer clic en el ícono de editar, la información se cargaba en el formulario ubicado sobre la tabla.
OP_3009_5.pngAnteriormente la actualización se confirmaba mediante una alerta breve con el texto Actualizado.
OP_3009_6.pngAl hacer clic en el ícono de eliminar, aparecía una alerta antigua con un mensaje genérico para confirmar el borrado.
OP_3009_7.pngAl borrar un crontab, la operación se informaba mediante una alerta breve con el texto Borrado.
OP_3009_8.pngDespués
Se incorporó la ruta Inicio / Menú / Gestión Crontabs, el botón de retorno y los botones Buscar, Limpiar y Guardar.
OP_3009_9.pngAhora cada crontab aparece en una tarjeta con su nombre, descripción, acción, fecha y hora de ejecución, especialidades y botones para editar o eliminar.
OP_3009_10.pngAl seleccionar Buscar sin diligenciar ningún criterio, el sistema muestra una alerta que solicita ingresar al menos un campo.
OP_3009_11.pngAl intentar guardar sin ingresar el nombre del crontab, se muestra una alerta que identifica el campo obligatorio.
OP_3009_12.pngAl intentar guardar sin diligenciar la descripción, el sistema informa mediante una alerta que ese campo es obligatorio.
OP_3009_13.pngDespués del ajuste se muestra una alerta que confirma que el registro se creó correctamente.
OP_3009_14.pngAhora el formulario presenta los datos del crontab seleccionado y habilita las acciones Cancelar y Actualizar.
OP_3009_15.pngDespués de la actualización se muestra un mensaje más descriptivo que informa que el registro se actualizó con éxito.
OP_3009_16.pngAhora se presenta una nueva alerta que identifica por nombre el crontab seleccionado y permite Aceptar o Cancelar la eliminación.
OP_3009_17.pngDespués se presenta la alerta de eliminación dentro de la nueva interfaz de tarjetas.
OP_3009_18.pngSe incorporó un paginador con las opciones Primera, Anterior, páginas numeradas, Siguiente y Última para navegar entre los registros.
OP_3009_19.pngGestión Correos
Después 
Gestión Correos cuenta con ruta de navegación, botón de retorno, formulario de destinatarios y botones Buscar, Limpiar y Guardar.
OP_3009_20.pngLos destinatarios se presentan en tarjetas con su nombre, código de tarea, correo, estado y opciones individuales para editar o eliminar.
OP_3009_21.pngAl realizar una búsqueda sin criterios el sistema muestra una alerta que solicita diligenciar al menos un campo.
OP_3009_22.pngAl intentar guardar un destinatario sin diligenciar el Código Tarea, el sistema muestra una alerta que identifica el campo obligatorio.
OP_3009_23.pngAl guardar correctamente un destinatario aparece una alerta que confirma la creación del registro.
OP_3009_24.pngAl pulsar Editar, los datos del destinatario se cargan en el formulario y se habilitan las opciones Cancelar y Actualizar.
OP_3009_25.pngAl actualizar los datos se presenta una alerta que informa que la operación terminó con éxito.
OP_3009_26.pngEl interruptor permite activar o desactivar un destinatario y muestra una alerta al cambiar su estado.
OP_3009_27.pngAhora se presenta una nueva alerta que identifica por el nombre del destinatario seleccionado y permite Aceptar o Cancelar la eliminación.
OP_3009_46.pngAl eliminar un destinatario se informa el resultado mediante una alerta en la interfaz.
OP_3009_28.pngGestión Correos dispone de paginación para navegar entre los destinatarios registrados.
OP_3009_29.pngGestión Condiciones
Después 
Gestión Condiciones dispone de ruta de navegación, retorno al menú, campos de parametrización y los botones Buscar, Limpiar y Guardar.
OP_3009_30.pngEl campo Crontab permite buscar y seleccionar la tarea programada a la cual se asociará una condición.
OP_3009_31.pngCada condición se visualiza en una tarjeta con el crontab asociado, acción, código, descripción, valor, tipo de dato, estado y opciones de administración.
OP_3009_32.pngAl intentar buscar condiciones sin criterios, el sistema muestra una alerta que solicita ingresar al menos un campo.
OP_3009_33.pngAl intentar guardar sin seleccionar un crontab se muestra una alerta que solicita diligenciar ese campo obligatorio.
OP_3009_34.pngAl registrar correctamente una condición se muestra una alerta que confirma la creación del registro.
OP_3009_35.pngAl pulsar Editar, los datos de la condición se cargan en el formulario y se habilitan las opciones Cancelar y Actualizar.
OP_3009_36.pngAl actualizar los datos de la condición se presenta una alerta que informa que la operación terminó con éxito.
OP_3009_37.pngEl interruptor permite cambiar el estado de una condición entre activo e inactivo y notifica el resultado.
OP_3009_38.pngAhora se presenta una nueva alerta que identifica por el código de la condición seleccionada y permite Aceptar o Cancelar la eliminación.
OP_3009_47.pngAl eliminar una condición se informa el resultado mediante una alerta en la interfaz.
OP_3009_39.pngGestión Condiciones dispone de paginación para navegar entre las condiciones registradas.
OP_3009_40.pngAl momento de realizar las pruebas de los envíos de contratos a vencer se guarda el registro en (contratos_proximos_a_vencer.log)
OP_3009_41.pngCuando no se encuentras contratos próximos a vencen se registra lo siguiente en el .log
OP_3009_42.pngCuando existen contratos próximos a vencer en el rango de DIAS_NOTIFICACION ajustado desde Gestion Condiciones se realiza el envió y se registra en el .log
OP_3009_43.pngCuando existe mas de un contrato próximo a vencer se realiza el envió de todos los contratos al correo con el Código Tarea: CONTRATOS_PROXIMO_VENCIMIENTO y estado: Activo, asociado con el crontab Enviar email a contratos próximos a vencer con la Acción: enviar_email_contratos_proximo_vencimiento.
```
