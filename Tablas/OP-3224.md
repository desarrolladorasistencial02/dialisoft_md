**Comentario 47662 · 2026-10-02T14:48:42.815-0500 · Carlos Santiago Gonzalez Cuellar**

```
Novedades y Modificaciones
Se ajusta el manejo de los valores del buscador en la creación de campos de consulta, validando y normalizando la información recibida para evitar errores de compatibilidad con PHP 8.4 cuando el parámetro buscador no contiene una estructura de arreglo válida en el módulo de Administración de Maestros.
Archivo: system_modules/Tablas/views/IndexHTML.class.php
Función: CrearBuscador
Antes:
Se accedía directamente a $request['buscador'][$fieldName['name']].
Se asumía que $request['buscador'] siempre estaba definido y correspondía a un arreglo.
Cuando buscador contenía un valor de tipo diferente a un arreglo, PHP 8.4 generaba el error Cannot access offset of type string on string.
El valor del campo se enviaba directamente a CrearCampos() desde $request['buscador'].
OP-3224_1.pngDespués:
Se obtiene la información de buscador mediante $request['buscador'] ?? [], estableciendo un arreglo vacío cuando no existe.
Se valida que $buscador corresponda a un arreglo; en caso contrario, se reemplaza por un arreglo vacío.
Se obtiene previamente el valor correspondiente al campo mediante $buscador[$fieldName['name']] ?? ''.
Se utiliza $valor_campo al generar el campo mediante CrearCampos(), evitando acceder directamente a una posición de una estructura que podría no ser válida.
Se mantiene la generación de los campos del buscador utilizando la información disponible y se evita el error producido durante la migración a PHP 8.4.
OP-3224_2.png
```
